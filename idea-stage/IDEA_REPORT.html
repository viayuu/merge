URS 专家模型合并：调研结论与实验路线

日期：2026-11-16。已按用户最新要求更新实施口径：使用原数据、原评测，与原论文结果对照，不另建数据集。 代码与小样本检查状态见 实验追踪。

先回答三个问题

值得做吗？ 值得做小规模验证。本地 11 个 URS 单任务专家与通用模型架构一致，可以直接尝试参数平均。能否保留多任务能力仍需实测；merge 没有必然优于联合训练的保证。

先做什么？ 先统一评测与确认权重起点，再做 2→4→11 个专家的递进实验。先平均和插值，有真实共同 base 才加入 Task Arithmetic、TIES，随后再试 DARE。

如何判断 motivation？ 在原论文相同任务、数据与解码设置下，逐项比较合并模型与论文URS的gap，同时列出论文STL和可选本地URS复跑。差值以百分点表示，负数更好。先看2/4任务，再完整看11任务；本轮不沿用此前新数据集上的1%/置信区间判据。

Literature Landscape

本轮按“经典合并方法 → routing 近邻 → URS 适用条件”调研。5 篇重点论文已下载 PDF、抽取正文并阅读方法/限制；不声称全文逐字读完。论文与覆盖清单见 PDF 下载记录、coverage receipt。

方法/论文核心用途URS 首轮安排
Model soups, ICML 2022同坐标参数平均；greedy soup 需验证集选成员先用固定全专家均匀平均；不预设独立训练模型能落在同一低误差区域
Task Arithmetic, ICLR 2023共同起点上的任务 delta 相加只有真 base 可验证时运行标准版本；lambda=1/K 应等于平均
TIES, NeurIPS 2023清理小 delta、解决符号冲突、聚合同符号坐标第二条重点 merge 基线；固定 retain=20%、lambda=1；后续探索保留各配置结果
DARE, ICML 2024稀疏化并重缩放 delta，搭配 TA/TIES第二批；先小 drop、单专家自检、3个mask seeds
Fisher merging、RegMean用参数重要性/激活统计引导合并数据辅助后备，不能归为完全无数据，也非缺 base 的自动解法
Git Re-Basin先做功能保持的排列对齐再合并独立初始化的后备诊断；注意力、残差、hypernetwork 需专门对齐规则
AdaMerging, ICLR 2024用无标签样本调任务/层系数后备；原熵最小化不等于 routing 目标优化，不能直接借用 test-time tuning 协议

普通平均计算不需要 base，但上述文献的成功证据常来自共同预训练模型的不同微调分支。共同随机初始化、共同预训练起点和完全独立初始化应分别记录；不能仅因模型形状相同就混为一谈。经典方法详细笔记

Novelty Verification

已经有直接近邻，motivation pilot 仍值得做。 MPSF-FL（2026） 已在 VRP 中采用 TIES 参数聚合：多任务预训练后，多轮单任务客户端训练与全局合并。其 Algorithm 1 输出客户端模型集合，与本次“直接拿现成 URS 专家，一次离线得到固定部署模型”有具体设定差异。

MoSES（NeurIPS 2025） 已有复用专门求解器构成统一 solver 的动机，采用共享骨干、LoRA 专家和动态组合。它与固定单一权重合并不同，但使“复用单任务能力”本身不足以充当新贡献。

本轮未检出完全相同 URS 实验设定的已验证结果；这不是不存在先行工作的证明。当前研究问题是：不使用通用模型权重、不追加联合训练、不保留多个动态专家，能否从现成单任务专家得到一个接近 URS 的固定模型？ 成功只先支持可行性，后续论文贡献还需结合真实失败模式和结果确定。

新鲜上下文审阅给出 PROCEED，限于进入 motivation pilot；明确不能宣称首次 VRP merge、理论优于 URS或总训练更省。审阅具体模型身份没有运行端回执，因此不登记为通过完整工作流所需的身份验证收据。查新证据 · 审阅原文

与原论文怎样对比

使用 URS/dataset 原发布文件，直接调用原 DataFinder、DataReader、Tester。正式对照为N=100、原顺序前1000例、greedy+POMO、对称8/非对称128倍增强。原参考分数、包含硬编码值在内的原gap公式均保留，不新增或拆分校准/测试集。

论文结果CSV 的11条URS和STL数值已从v3第6页Table 2/3逐项核实。来源说明。汇总显示原 aug_gap、论文gap及 本次gap - 论文gap（百分点）；负值更好，不与相对百分比混写。

各模型保持同一任务顺序、seed、batch、POMO、增强及mask。关闭增强仍是POMO多起点；非对称随机node ID沿用原入口行为。小样本只作通路检查，不与论文1000例成绩作有效性对照；原论文值和本地通用URS重跑值分开显示。

若探索不同merge系数，保留各配置结果并注明同数据集上的探索；不宣称独立held-out确认。原专家跨任务评测可帮助区分单专家泛化与融合收益，但本轮不增加搜索框架或新的评测体系。
