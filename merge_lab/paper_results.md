# URS 原论文对照数据

来源：[URS arXiv v3](https://arxiv.org/abs/2509.23413v3)，2026-08-11 修订；本地 PDF 为 `papers/2509.23413.pdf`。所有11个源任务数字来自 PDF **第6页（页面印刷页码同为6）Table 2 和 Table 3**。本次用该页渲染图像逐个核对了正文提取文本；两种读取方式一致。

`paper_results.csv` 每行是一个任务、N=100、1,000实例的论文结果。`paper_urs_gap_pct` 是通用 URS，`paper_stl_gap_pct` 是该任务自己的 URS-STL，不是一个固定专家跨11任务的结果。数字单位为百分数，例如 `6.13` 代表 `6.13%`；PCTSP 的 URS-STL 为 **-0.09%**，保留原表符号。

论文 §4.1（第6页；推理设置续于第7页）规定每任务1,000实例，报告对称×8、非对称×128 instance augmentation 后的结果。当前代码 `URS/args.py` 默认同样为8/128；ATSP、ACVRP对应128，其余这9个任务对应8。正式对照使用发布数据、N=100、原读取顺序的前1,000例、原Tester增强后的gap；64例或关闭增强的自检结果不属于该表的匹配设置。

表2/3未提供URS/STL的平均目标值，因此CSV不填推测objective。论文对照差定义为 `本次官方aug_gap - paper_urs_gap_pct`，单位是**百分点(pp)**，负数更好；与STL比较同理。保留原代码的oracle/reference和gap计算，不把论文gap或通用模型预测当作数据标签。

本地与论文的数值并排呈现，论文值标为paper，本地复跑标为local。仅按相同配置评测并不保证数值逐位相同，特别是非对称任务的随机node IDs。论文给定的是两位小数，这个精度不应在汇总时补造。时间列未转录，避免把不同执行环境时间直接当作模型速度差异。
