# URS 五任务 CSP + LOT 实验结果

完成 **100/100** 项：本轮新评测 97 项，复用历史 LOT 3 项。对照为旧的、未续训 URS 多任务 base。

原五任务各1000个N100实例，greedy、POMO多起点、8倍增强；增强gap（%）越低越好，五任务等权平均。

N64使用三次固定seed取样；N1000使用固定原集合全量一次，std记为“—”，不表示不确定性为零。取样重复不是重训专家。
