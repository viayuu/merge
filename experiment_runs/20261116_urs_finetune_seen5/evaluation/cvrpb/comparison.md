# URS 原数据集结果对比

Gap 沿用原 DataReader/Tester 的参考值及公式；差值单位为百分点，负值更好。
仅原 dataset、N=100、1000例、greedy 与论文增强倍数匹配的行计算论文差值。
小样本/无增强仅用于检查通路，不视为论文成绩复现。论文数值保留原表精度。
