# 固定提案：复用 URS 单任务专家得到统一模型

日期：2026-11-16。状态：研究方案，未有 pilot 结果。

研究问题：能否将已发布的 11 个 URS 单任务专家离线合并成一个与 URS 同参数量的固定模型，保留多任务求解能力，在相同推理预算下接近通用 URS？

主轨只使用发布专家。先试参数平均/两模型插值；共同训练底座得到证实时，再试 Task Arithmetic、TIES 与 DARE。URS 原有条件参数生成、约束输入和可行性 mask 保留；不按任务换 checkpoint，不把通用 URS 注入合并，不进行额外联合训练。

最小证据：独立校准/测试，2→4→11任务递进，匹配实际 POMO、augmentation、随机 node IDs；逐任务目标差、可行率、最差任务、paired CI。建议完整 seen-task 宏平均退化95% CI上界≤1%，最差任务平均退化≤3%，观测可行率100%。这是事前标准，不是已取得结果。

对照：URS 通用模型、原任务专家、校准选择的最佳固定单专家、uniform及符合起点条件的merge方法。若合并无法优于最佳固定专家，不宣称多专家融合收益。

已知前提：本地12个模型结构兼容，但共同base不明；独立初始化可能使直接平均失败；部分任务闲置分支会稀释专用权重。失败先定位坐标/分支/任务冲突，另训共享起点专家必须单列成本和设定。

最接近工作是 MPSF-FL 的多轮TIES联邦聚合与 MoSES 的动态专家组合。因此目前不主张首次VRP merge。目标先取得“现成URS专家、一次离线固定单模型”的经验信号；99个未见任务与新算法设计后置。
