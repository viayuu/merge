几个会影响后续判断的结论：

- CEMM 使用“已训练通用 base → 单任务微调专家”；当前 URS 证据指向“随机初始化 → 单任务长期训练”。相同 seed、相同架构和共同预训练 base 是三件事。
- CEMM 单模型结果已证明其设置下的合并可以有效，但不能由此推出任意现成 URS 专家都可直接合并，也不能把“在 VRP 中合并专家”本身当作新贡献。
- “不显式读 base 文件”“不使用原训练数据”“不进行梯度优化”“没有额外推理成本”必须分别判断，不能统一简称为无训练/无数据。
- 当前可在推断同组专家上使用重建随机初始化 base 做探索。完整历史起点仍未获得；已有 45 项平均/插值负结果保持不变。
- 参数子集、层级权重、功能保持、子空间和神经元对齐分别处理不同问题，不能仅凭方法在分类或语言模型上有效就断言适用于 URS。
